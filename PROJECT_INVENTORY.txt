   - Create new project
   - Copy URL & API Key to .env

2. Execute Database Schema
   - Go to Supabase SQL Editor
   - Paste src/database/schema.sql
   - Execute all statements

3. Push to GitHub
   - git init
   - git add .
   - git commit -m "Initial commit"
   - git remote add origin https://github.com/yourusername/youcaps-backend
   - git push -u origin main

4. Create Render Web Service
   - Go to https://dashboard.render.com
   - New Web Service
   - Connect GitHub
   - Set environment variables from .env
   - Deploy

5. Configure Mollie Webhook
   - Go to https://mollie.com
   - Settings → Webhooks
   - URL: https://youcaps-backend.onrender.com/api/payment/webhook
   - Copy secret to MOLLIE_WEBHOOK_SECRET

6. Verify Deployment
   - curl https://youcaps-backend.onrender.com/health
   - curl https://youcaps-backend.onrender.com/health/ready
